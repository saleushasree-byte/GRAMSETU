\# 🌾 GRAMSETU



\### Empowering Rural Communities Through Digital Technology



GRAMSETU is a digital platform designed to connect rural communities with essential services, agricultural guidance, government schemes, healthcare information, education, and market opportunities.



\## 🚀 Features



\- \*\*Krishi Sahayak\*\* – Agricultural guidance and crop-related support.

\- \*\*Vikas Naksha\*\* – Rural development information.

\- \*\*Swasthya Mitra\*\* – Healthcare information and support.

\- \*\*Gyan Dhara\*\* – Educational resources.

\- \*\*Yojana Sathi\*\* – Government scheme information.

\- \*\*Bazaar Setu\*\* – Market and selling opportunities.



\## 🛠️ Technologies Used

\## ⚙️ How to Run



\### Backend



```bash

cd backend

pip install flask flask-cors

python app.py

```



\### Frontend



```bash

cd frontend/GramSetu-main

npm install

npm run dev

```
